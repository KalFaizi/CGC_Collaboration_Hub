What is it costing and consuming?

Almost all of the cost is the fixed premium-licence fee; credits add under 3% and tokens carry no separate charge. So every extra hour saved goes straight to the return, while rising consumption is a budget signal rather than a problem today.

How this dashboard was built

  • Change over time uses line charts (active users, value vs cost, credits, tokens, incident rate). Category comparisons use sorted horizontal bars. Department value uses a scatter because the story is a relationship. Licence utilisation uses a dot plot because the differences sit close to an 81% benchmark.
  • Red always marks the element the headline is about; grey is context. Severity in the events chart uses three shades of the same red, darkest for high.
  • Two axes are truncated (value vs cost from RM20k, licence utilisation from 40%), each marked with ≁ and footnoted. All bar charts start at zero.
  • The division filter recalculates every chart that has division data. Use-case, workload and policy-event charts are organisation-wide in the source, so they stay fixed and say so.
  • Value, cost and ROI rest on the dataset's demo assumptions: RM145 per premium seat per month and RM0.12 per credit; Copilot access for all staff is assumed covered by the existing E5 licence.
