Changing the hub

Open this file in Notepad and edit the APP_CONFIG block near the top of the script: titles, team, days, tabs, logo and the full session list. Sessions only appear for people in the team list.

For live sync across the team's devices, fill in the optional Firebase settings in APP_CONFIG. Without them, data is saved in each browser only.
